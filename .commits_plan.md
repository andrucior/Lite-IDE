# Feature: Historia zmian (Edit History)

Tracker commitów dla implementacji historii edycji dokumentów.

---

## Commit 1: `feat(domain): add HistoryEntry model and wire into DocumentRoom`
- [x] **DONE**
- Nowy plik `domain/HistoryEntry.scala` — case class z polami: `op`, `authorSessionId`, `authorDisplayName`, `timestamp`, `version`
- Zmiana `DocumentRoom.State.history` z `Vector[Op]` na `Vector[HistoryEntry]`
- Aktualizacja OT pipeline w `submitEdit` — tworzenie `HistoryEntry` z metadanymi
- Dodanie `def historyEntries: F[List[HistoryEntry]]` do traitu `DocumentRoom`
- Lookup displayName z `presence` ref wewnątrz `submitEdit`

## Commit 2: `feat(api): add GET /api/documents/:id/history endpoint`
- [x] **DONE**
- Dodanie route `GET /api/documents/:id/history` do `Routes.scala`
- Endpoint czyta historię z aktywnego `DocumentRoom` przez `RoomRegistry`
- Fallback: jeśli room nie istnieje (dokument nie jest otwarty), zwraca `[]`
- JSON response: `[{ op, author, timestamp, version }]`
