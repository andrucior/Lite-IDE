# Lite-IDE
W ramach projektu planowaliśmy zrobić edytor kodu umożliwiający programowanie zespołowe w czasie rzeczywistym,
wzorowany trochę narzędziami do wspólnej edycji dokumentów, np. Google Docs. 
Do planowanych funkcjonalności należą: 
- edycja kodu w czasie rzeczywistym przez kilku użytkowników, 
- widoczność ich kursorów i zaznaczeń oraz podświetlanie składni. 

W ramach dodatkowych wymagań możliwa jest również implementacja systemu 
uprawnień (właściciel / edytor / obserwator), a takze historia zmian.
